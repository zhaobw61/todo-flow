# W4 开发执行

## 目标

读取 W3 生成的 `current-batch.md`，按照任务范围完成本批开发工作。

串行模式由 Claude 按顺序开发；并行模式将互不冲突的任务交给不同 SubAgent。开发过程中必须保护用户已有修改，不得扩展任务范围。

本节点负责开发和基础验证，但不负责最终代码审查。

## 输入

- W1 生成的项目状态摘要；
- 当前 Feature 的 `requirements.md`；
- 当前 Feature 的 `design.md`；
- 当前 Feature 的 `tasks.md`；
- W3 生成的 `current-batch.md`；
- 与当前任务相关的 `AGENTS.md`；
- 当前 Git 状态和需要保护的已有修改。

## 执行步骤

1. 读取 `current-batch.md`，确认本批任务、执行模式和验收标准；
2. 重新检查 Git 状态，确认需要保护的用户修改；
3. 读取与本批任务相关的 `AGENTS.md` 和项目规则；
4. 根据任务类型调用对应的开发 Skill；
5. 如果是串行模式，由 Claude 按任务依赖顺序逐个开发；
6. 如果是并行模式，每个 SubAgent 只领取一个独立任务，并限制其可修改的文件范围；
7. 使用最小范围修改完成任务，不处理本批次之外的功能；
8. 按 `current-batch.md` 中规定的顺序整合开发结果；
9. 对每个任务执行约定的基础验证；
10. 汇总修改文件、验证结果和未解决问题，交给 W5 进行代码审查。


## 能力调度规则

### Skills

根据任务类型选择对应 Skill：

- 页面、组件和交互开发：调用 `frontend-development` Skill；
- React 状态和数据流修改：调用 `react-development` Skill；
- 样式和移动端适配：调用 `responsive-ui` Skill；
- 不属于以上类型时，先检查项目已有 Skills，不得虚构不存在的 Skill。

Skill 只提供专业方法和约束，实际开发仍由 Claude 或 SubAgent 执行。

### SubAgents

只有 `current-batch.md` 明确选择并行模式时，才创建 SubAgent。

每个 SubAgent 必须收到：

- 唯一的任务 ID 和目标；
- 允许修改的文件；
- 禁止修改的文件；
- 对应验收标准；
- 验证方法；
- 需要保护的用户修改；
- 完成后必须返回的修改摘要和验证结果。

SubAgent 不得继续拆分或扩大任务范围，不得提交、推送或部署代码。

### 串行与并行

- 串行模式：Claude 按依赖顺序执行全部任务；
- 并行模式：SubAgent 分别完成独立任务，Claude 负责检查和整合结果；
- 发现文件冲突、接口依赖或规格不明确时，停止并行，改为串行处理。

## 路由规则

### 进入 W5

满足以下条件时进入 W5：

- `current-batch.md` 中的任务已经完成开发；
- 修改没有超出本批任务范围；
- 已执行约定的基础验证；
- 已生成完整的 `development-report.md`；
- 没有会阻止代码审查的未解决问题。

### 返回 W3

如果开发过程中发现任务依赖错误、任务存在文件冲突，或者当前批次无法按原计划执行，则停止开发并返回 W3 重新规划任务。

### 返回 W2

如果开发过程中发现需求、验收标准或技术设计不明确，则停止开发并返回 W2 补充规格。

## 完成条件

只有同时满足以下条件，W4 才算完成：

- 本批任务均已按照 `current-batch.md` 完成；
- 没有修改禁止修改的文件；
- 用户已有修改没有被覆盖或删除；
- 串行任务遵守依赖顺序；
- 并行任务已经完成整合且没有文件冲突；
- 每个任务都执行了约定的基础验证；
- 已生成 `development-report.md`；
- 修改结果已经准备好交给 W5 审查；
- 尚未把任务标记为最终完成。

## 停止条件

出现以下任意情况时暂停并报告：

- 需求、设计和任务描述互相矛盾；
- 必须修改本批范围之外的文件才能继续；
- 预计修改与用户已有修改冲突，且无法安全合并；
- SubAgent 返回的结果相互冲突；
- 基础验证持续失败，且无法在当前任务范围内修复；
- 需要新增账号、密钥、付费服务或外部权限；
- 操作可能造成数据丢失或不可逆修改；
- 无法满足任务的验收标准。

停止时说明：

- 当前执行到哪个任务；
- 已完成哪些修改；
- 停止的具体原因；
- 已经执行过哪些验证；
- 应当返回 W2、返回 W3，还是需要用户决定。
