# TodoList 课程作业说明：按完成状态筛选

## 功能范围

TodoFlow 是一个中文 TodoList 页面，支持以下功能：新增任务、标记完成或未完成、删除任务、「全部 / 待完成 / 已完成」筛选、按名称搜索、显示完成百分比和剩余数量、用 `localStorage` 保存数据、在 390px 手机宽度下使用。

本次提交的改动：

- `app/page.tsx`：在筛选视图中用键盘切换某项完成状态后，焦点会移到下一项、上一项、搜索框或当前筛选按钮，不再丢失（任务 T6，对应 AC16）。
- `app/globals.css`：区分筛选按钮的悬停样式和选中样式（任务 T7，对应 AC15）。
- 规格文件：`requirements.md`、`design.md`、`tasks.md`（T1–T7 均已完成）。

## 启动方式

需要 Node.js 22.13.0 或更高版本。

```bash
npm install
npx vite --config vite.pages.config.ts --port 5173
```

启动后打开 http://localhost:5173/。

不要用 `npm run dev`。它会把 `pages/main.tsx` 当作 SSR 页面处理，报 `document is not defined`（见 `AGENTS.md`）。

生成 Cloudflare Pages 静态文件：

```bash
npm run build:pages   # 输出到 pages-dist/
```
