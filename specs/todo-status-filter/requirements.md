# 需求：按完成状态筛选

## 背景和目标

清单中同时有已完成和未完成的任务时，用户需要只看其中一类，以便专注于还没做完的事，或回顾已经做完的事。本功能让用户在「全部、未完成、已完成」三种视图之间切换。

代码中已有实现（未验收）：`app/page.tsx` 已包含 `Filter` 类型、`filterLabels`、按 `filter` 派生的 `visibleTodos` 以及筛选按钮组，`app/globals.css` 已包含筛选按钮样式。但该功能此前没有需求、设计和任务文档，尚未找到本功能对应的实际验收记录。本次目标是补齐规格，并为后续节点安排对现有实现的核对和验收，不重复开发。

一句话描述：让用户一键切换只看全部、未完成或已完成的任务。

## 包含范围

- 列表工具栏中的三个筛选按钮：「全部」「待完成」「已完成」（需求原文中的「未完成」对应界面现有文案「待完成」）；
- 默认选中「全部」；
- 点击按钮切换当前筛选，列表只显示符合该状态的任务；
- 当前选中的按钮有视觉高亮（`.filter.active`），并通过 `aria-pressed` 表达选中状态；
- 按钮组有可访问名称「筛选任务」（`role="group"`）；
- 全部任务非空、当前筛选下没有任务且搜索框为空时，显示「这里没有任务」空状态；
- 全部任务为空时，无论当前筛选是什么，都显示全局空清单提示「清单还是空的」；
- 筛选与已有的按名称搜索同时生效（取交集）；
- 切换筛选不改变进度百分比、「N 项待完成」和底部统计（统计基于全部任务）；
- 390px 手机宽度下按钮可点击、无横向滚动；
- 按 code-review-report.md S1-2 的用户决定，最小修改 `app/globals.css` 中 `.filter` 的悬停/选中规则：未选中按钮悬停时使用浅绿色样式，与选中按钮的深绿底白字区分（对应 AC15、tasks.md 的 T7）。

## 不包含范围

- 除按 S1-2 决定最小修改 `app/globals.css` 中 `.filter` 悬停/选中规则（第 69 行）外，不修改业务代码（`app/`、`pages/`、`worker/`、`db/` 等）；`app/page.tsx` 和其他样式规则不动；
- 不重写或重新开发筛选功能；
- 不修改「待完成」文案（不改为「未完成」）；
- 不持久化筛选状态：以代码现状为准，筛选状态只存在于内存（`useState`），不写入 `localStorage` 或 URL，刷新后回到「全部」；
- 不增加新的筛选维度（如按日期、优先级）；
- 不修改任务数据结构和存储格式；
- 不修复与本功能无关的既有问题（如文档记录的 lint 基线问题；`tests/rendered-html.test.mjs` 是否适用于当前页面尚未核实）。

## 验收标准

以下验收标准均需在后续节点通过实际操作或测试验证；本次 W2 未运行任何验证。

1. AC1：页面存在一个可访问名称为「筛选任务」的按钮组，内含「全部」「待完成」「已完成」三个按钮，顺序固定；
2. AC2：首次打开页面（或刷新后），「全部」按钮处于选中状态（`aria-pressed="true"`，带 `active` 样式），其余两个为 `aria-pressed="false"`；
3. AC3：默认 3 项任务时，将「使用 Antigravity 测试页面」标记完成，点击「全部」，列表显示全部 3 项；
4. AC4：在 AC3 的状态下点击「待完成」，列表只显示「让 Claude 审查 TodoList 代码」和「部署到 Cloudflare Pages」；
5. AC5：在 AC3 的状态下点击「已完成」，列表只显示「使用 Antigravity 测试页面」；
6. AC6：每次点击后，只有被点击的按钮为 `aria-pressed="true"` 并带高亮样式；
7. AC7：在「已完成」视图中取消勾选该任务，它立即从当前列表中消失；在「待完成」视图中勾选一项，它也立即从当前列表中消失；
8. AC8：全部任务非空、当前筛选下没有任务、且搜索框为空时（例如有任务但没有已完成任务时点击「已完成」），显示「这里没有任务」和「换个筛选条件看看。」；
9. AC9：切换筛选前后，进度百分比、「N 项待完成」和底部「N 项任务 / N 项已完成」数字不变；
10. AC10：筛选与搜索取交集：在 AC3 的状态下选择「待完成」并搜索「部署」，只显示「部署到 Cloudflare Pages」；选择「已完成」并搜索「部署」，显示「没有找到匹配的任务」空状态；
11. AC11：选择「已完成」后刷新页面，任务数据保留，筛选回到「全部」（筛选状态不持久化）；
12. AC12：390px 宽度下筛选按钮完整可见、可点击，页面无横向滚动；浏览器控制台无阻断性错误；
13. AC13：`npm run build` 能完成；用 `npx eslint app` 与基线对比，本功能不引入新的 lint 错误（基线已有错误按 `AGENTS.md` 说明处理，不在本功能范围内）；
14. AC14：全部任务为空时（在独立浏览器测试上下文中删除全部任务），无论当前选中哪个筛选，都显示「清单还是空的」和「在上方输入一件想完成的事吧。」，不显示「这里没有任务」；
15. AC15：鼠标悬停在未选中的筛选按钮上时，该按钮显示浅绿色背景 `#eef1ea`、深绿色文字和边框（`var(--forest)`），与选中按钮的深绿底白字可以清晰区分；悬停在已选中按钮上时仍为深绿底白字；悬停不改变任何按钮的 `aria-pressed`。
