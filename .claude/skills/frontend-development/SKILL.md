# Frontend Development

## 目标

按照当前 Feature 的规格和 `current-batch.md`，以最小修改范围完成页面、组件和交互开发。

不得扩大任务范围，不得覆盖用户已有修改，不得在未经允许时提交或推送代码。

## 使用前读取

- 当前 Feature 的 `requirements.md`；
- 当前 Feature 的 `design.md`；
- W3 生成的 `current-batch.md`；
- 与目标文件相关的 `AGENTS.md`；
- 当前 Git diff 和需要保护的修改；
- 需要修改的现有页面和组件。

## 执行规则

1. 先理解现有页面结构和组件风格，再开始修改；
2. 优先复用已有组件，不创建功能重复的组件；
3. 只修改 `current-batch.md` 允许的文件；
4. 使用语义化 HTML，并保留键盘操作和无障碍能力；
5. 不为了当前功能进行无关重构；
6. 不随意增加第三方依赖；
7. 涉及 React 状态时调用 `react-development` Skill；
8. 涉及移动端和响应式样式时调用 `responsive-ui` Skill；
9. 完成后执行本任务约定的基础验证；
10. 返回修改文件、完成内容和验证结果。

## 完成条件

- 页面、组件或交互满足对应验收标准；
- 修改没有超出允许的文件范围；
- 没有破坏现有功能和无障碍能力；
- 已执行约定的基础验证；
- 已返回修改摘要和验证结果。

## 停止条件

出现以下情况时停止并返回 W4：

- 规格或验收标准不明确；
- 必须修改任务范围外的文件；
- 需要新增未经批准的依赖；
- 修改会覆盖用户已有工作；
- 无法在当前 Skill 的职责范围内完成任务。
